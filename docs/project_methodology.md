# Méthodologie
1. Cadrage : suivre la santé financière et identifier les écarts budgétaires.
2. Collecte : CSV synthétiques 2025 concernant revenus, charges, départements et budgets.
3. Préparation : Pandas convertit les dates et montants, supprime doublons et lignes incomplètes.
4. Stockage : MySQL, tables définies dans sql/schema.sql.
5. Analyse : SQL calcule tendances, charges par catégorie/département, résultat et écarts.
6. Visualisation : Power BI et mesures DAX.
7. Validation : comparer les agrégats SQL/Power BI et tester les filtres.
8. Portfolio : présenter contexte, architecture, KPI, captures d'écran et limites des données fictives.
