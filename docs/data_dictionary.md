# Dictionnaire de données
- revenues : revenue_id (identifiant), revenue_date (date), category (type de revenu), amount_tnd (montant TND), department_id (département).
- expenses : expense_id, expense_date, category (charge), department_id, amount_tnd, description.
- departments : department_id, department_name.
- budgets : budget_id, budget_month, category (indicateur budgétaire), budget_amount_tnd.
- activities : activity_id, activity_name, description.
Toutes les données sont synthétiques et destinées à la démonstration.
